To access the Billing Service:

  1. Get the service name:
     $ kubectl get svc -n {{ .Values.namespace.name }} {{ include "billing-service.fullname" . }}

  2. Port-forward to access locally:
     $ kubectl port-forward -n {{ .Values.namespace.name }} svc/{{ include "billing-service.fullname" . }} 8082:{{ .Values.service.port }}

  3. Access the service:
     - Health: http://localhost:8082/actuator/health
     - Metrics: http://localhost:8082/actuator/prometheus
     - API Docs: http://localhost:8082/swagger-ui.html
