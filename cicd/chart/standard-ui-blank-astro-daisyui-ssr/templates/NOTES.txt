4. Runtime environment variables are managed via ConfigMap (non-sensitive) and
   Kubernetes Secrets (sensitive). The application uses:

   ConfigMap name (envFrom source):
     {{ include "standard-ui-blank-astro-daisyui-ssr.fullname" . }}-config

   Non-sensitive (set under app.env):
     RESEND_FROM       – sender address for outgoing emails
     RESEND_FROM_NAME  – optional display name for the From field
     RESEND_TO         – recipient address for contact form submissions
     RESEND_API_KEY    – Resend API key (non-secret fallback; prefer secretEnv)

   Sensitive (set under app.secretEnv, provisioned as a Kubernetes Secret):
     RESEND_API_KEY  – Resend API key for email delivery

   Example values file configuration:
     app:
       env:
         RESEND_FROM: "noreply@example.com"
         RESEND_TO: "contact@example.com"
       secretEnv:
         RESEND_API_KEY:
           secretName: standard-ui-blank-astro-daisyui-ssr-secrets
           secretKey: RESEND_API_KEY

   Create the Secret before deploying:
     kubectl create secret generic standard-ui-blank-astro-daisyui-ssr-secrets \
       --from-literal=RESEND_API_KEY=re_... \
       --namespace <namespace>
